Instalación

Enlaza la hoja de estilos y utiliza los elementos HTML habituales.

<link rel="stylesheet" href="semantic.css">

<section>
  <article>
    <h3>Ejemplo de tarjeta</h3>
    <p>Título y descripción dentro de un artículo.</p>
  </article>
</section>

El HTML describe el contenido. El CSS decide cómo presentarlo.

Preguntas frecuentes

¿Necesito clases para cada componente?

No. Las etiquetas definen la presentación: nav crea navegación, details un acordeón y los artículos dentro de una sección forman una cuadrícula.

¿Cómo cambio los colores?

Sobrescribe las variables --s-col-* en :root. El primario, el foco y las superficies se comparten entre todos los componentes.

¿Cómo funciona en móvil y en modo oscuro?

Las cuadrículas se reorganizan según el espacio y la paleta sigue la preferencia del sistema. El aside con popover se abre desde el menú móvil y se cierra con Escape o al tocar fuera.

¿Todo esto funciona sin JavaScript?

Sí. Los formularios, acordeones y paneles emergentes utilizan comportamientos nativos del navegador. Búsquedas, persistencia y lógica de aplicación se conectan por separado cuando tu proyecto las necesita.

Agregar Semantic CSS

Copia semantic.css a tu proyecto y enlázalo desde el documento.

<link rel="stylesheet"
      href="semantic.css">

No requiere instalación ni compilación. Los estilos se aplican a los elementos HTML del documento.
